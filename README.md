# Doctoral CV - Jayanath Jayarathna

Streamlit-based academic CV and digital profile for doctoral applications in Artificial Intelligence.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Deployment

Deploy this repository with Streamlit Community Cloud using `app.py` as the app entry point.

## Before publication or application use

The CV is a draft. Confirm qualification titles against the certificates, employment dates and official designation, contact details, and project evidence. Do not add unverified project metrics or claims.
